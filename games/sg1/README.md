# Stargate SG-1: The Alliance (Xbox) - native Windows port

Put your own copy of the game in the `assets` folder (`default.xbe` with `System`, `Maps`, `Textures` ... beside it, or the disc image), then start `SG1.exe`. The first start builds the game code from your `default.xbe`, which takes a few minutes once.

Insert opens the settings menu (mouse, field of view, widescreen, display, HD textures), V the voice menu in a match, F9 frees the mouse.

Full instructions, building from source and the HD texture pack: https://github.com/SinonVT/Stargate-SG-1-The-Alliance-recomp

No game files or game code are included. This is not an official project and has no affiliation with the game's rights holders.
